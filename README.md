# 我的工作台

基于 React、TypeScript、Vite 和 Motion 的个人工作台。页面沿用 `ai_studio_code (17).html` 的三栏布局、橙色芯片环轨和日报翻页视觉。

## 本机运行

使用 Node.js 22.12 以上版本（或 20.19 以上版本）与 npm：

```bash
npm install
npm run dev
```

浏览器访问 `http://127.0.0.1:5173`。开发服务器只监听本机地址，端口占用时会报错。

```bash
npm run test
npm run build
npm run preview
```

生产预览地址为 `http://127.0.0.1:4173`，构建产物位于 `dist/`。

## 当前功能

- 待办新增：输入内容后按回车或点击“添加”，支持最多 300 个字符。
- 完成归档：宽窗口播放“待办汇入 → 芯片环轨 → 日报写入”的 SVG 粒子动效，然后把任务收进今日日报。
- 日报翻页：查看最近工作日及已保存记录对应的历史日期，日期与计数自动计算。
- 本机保存：待办与完成记录存入当前浏览器的 localStorage，刷新后恢复。
- 响应式布局：宽窗口三栏，中等窗口核心置顶，窄窗口纵向排布。
- 减少动态效果：遵循系统偏好；窄窗口直接归档，保留卡片过渡。
- 空状态、键盘焦点和存储失败提示。

首次打开包含示例记录。页面尚未读取 Codex、Claude Code、WorkBuddy 或禅道的真实记录，工具卡片显示“待接入”。本机保存仅属于当前浏览器及当前站点地址，清理站点数据会删除记录。

## 代码结构

```text
src/
  components/              工作台面板、日报书页、芯片和传输动效
  domain/workbench.ts       任务模型、日期、归档规则及缓存校验
  data/localRepository.ts   本机缓存读写入口
  App.tsx                  页面组合与交互协调
  styles.css               原型视觉及响应式状态
```

后续接入本机记录时可替换 `data/` 数据访问层，再为各工具增加适配器。界面组件与任务模型可继续用于 Tauri 桌面应用或带本机读取服务的网页工作台。

原始参考文件和 `workbench/index.html` 保留在仓库中。
