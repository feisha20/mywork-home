# 渠道图标

这些图标仅用于识别当前采集来源，按原比例缩放并保存在本机，页面不请求外部图像服务。

- `claude.png`：本机 Claude 应用的 `electron.icns`。
- `codex.png`：本机 Codex++ 应用的 `codex-plus-plus.icns`，用于当前 Codex 会话来源。
- `workbuddy.png`：本机 WorkBuddy 应用的 `icon.icns`。
- `zcode.png`：本机 ZCode 应用的 `icon.icns`。
- `gemini.svg`：[Google 官方 Gemini 彩色星标](https://www.gstatic.com/lamda/images/gemini_sparkle_v002_d4735304ff6292a690345.svg)，保留原始矢量图。
- `zentao.png`：[禅道官网图标](https://www.zentao.net/favicon.ico)。

图标与商标归对应产品所有。除 Gemini 保留 SVG 外，源文件转为 96×96 PNG，兼顾小尺寸显示与高分辨率屏幕；未重新绘制品牌标记。
